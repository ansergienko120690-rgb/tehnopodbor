# ТехноПодбор

Приложение для поиска и сравнения бытовой техники: каталог, мастер подбора, сравнение, 3D-осмотр моделей,
комплекты (наружный блок кондиционера, базы, насадки), отзывы и сводный рейтинг.

- `index.html` — всё приложение одним файлом (3D — three.js с cdn.jsdelivr.net).
- `tests/run.js` — автотесты (Playwright + Chrome).
- `.github/workflows/ci.yml` — на каждое изменение запускает тесты; из ветки `main` при успехе выкладывает сайт на GitHub Pages.

Основная версия с общими отзывами живёт на claude.ai; на GitHub Pages отзывы сохраняются только на устройстве.
Исходники сборки и история версий — в папке проекта «мои проекты Клод\Приложение Техника».
