# Как подключить живые цены магазинов

Приложение само не обращается к сайтам магазинов. Цены собирает посредник — сценарий GitHub Actions
(`tools/update_prices.mjs`). Он запускается каждый день в 06:17 по Москве, а также вручную:
Actions → ci → Run workflow. Источников два, их можно использовать вместе.

## Вариант 1. Ручной прайс (работает уже сейчас)

Файл `src/data/prices.csv`, по строке на модель:

```
id;price;shop;url
fridge-lg-ga-b419swjl;44990;Ситилинк;https://www.citilink.ru/product/...
```

`id` модели берётся из `src/data/catalog.json` — это поле `id` в паспорте реальной модели (последний объект строки)
или `категория-номер` для демо-моделей. Если поменять цену и загрузить файл в репозиторий, при следующем запуске
посредника цена обновится на сайте. Claude может пройтись по ссылкам магазинов и обновить прайс по просьбе
«обнови цены ТехноПодбора».

## Вариант 2. Прайс-листы магазинов через партнёрскую сеть (цены обновляются сами)

Магазины отдают прайс-листы (товарные фиды в формате YML/XML) участникам своих партнёрских программ.
Открытого бесплатного API цен у российских магазинов нет, поэтому этот путь — основной.

Шаги (делаете вы: нужна регистрация и согласие с условиями сети):

1. **Регистрация вебмастера.** Зарегистрируйтесь в партнёрской сети, где есть магазины техники с товарными фидами.
   Примеры: Admitad (admitad.com), Pampadu (pampadu.ru, раздел «Товарные фиды»). Регистрация бесплатная.
2. **Площадка.** Добавьте площадку — сайт приложения: `https://ansergienko120690-rgb.github.io/tehnopodbor/`
   (тип «сайт / сравнение цен»). Сеть проверяет площадку, это может занять несколько дней.
3. **Программы магазинов.** В каталоге программ включите фильтр «Товарный фид» (Admitad: Store → фильтр
   Product Feed) и подайте заявки в магазины техники. Каждый магазин одобряет площадку сам.
4. **Ссылка на фид.** После одобрения: страница программы → «Товарные фиды» → выбрать площадку и фид →
   скопировать ссылку XML. (В Admitad также: «Товарные фиды → Оригинальные» → «Сгенерировать».)
   Можно сузить фид шаблоном экспорта или фильтрами, чтобы файл был меньше.
5. **Секрет в GitHub.** Репозиторий → Settings → Secrets and variables → Actions → New repository secret:
   имя `PRICE_FEEDS`, значение — ссылки на фиды, по одной в строке. Ссылки содержат ваш ключ доступа,
   поэтому они хранятся только в секрете, не в файлах.
6. **Проверка.** Actions → ci → Run workflow. В журнале шага «Обновить цены» будет строка вида
   `Магазин (N из M)` — сколько моделей каталога найдено в фиде.

Как посредник сопоставляет товары: по «бренд + модель» из каталога (регистр и знаки не важны).
Если название в фиде другое, добавьте соответствие в `src/data/price_map.json`:
`{ "<id предложения в фиде>": "<id модели в каталоге>" }`. Из нескольких магазинов берётся минимальная цена.

Ссылки в фидах партнёрские — покупка по ним приносит площадке вознаграждение по условиям программы.
Перед публичным запуском проверьте требования сети к маркировке рекламы.
